# データの判断根拠

`src/data` 以下のJSONに入力した日付について、採用した日付と根拠・出典を記録する。
全メンバーを記載し、公式プロフィールなどに従っただけの場合もその旨を記載する。

- 採用した根拠を先に書き、採用しなかった候補は「参考」として残す
- 「暫定」は、確かな根拠が得られていないが、根拠を示した上で仮に決めた値を表す
- 「グループ卒業日」に記載がないメンバーは現役を表す
- 卒業により削除された公式プロフィールは、スナップショットが見つかればそのリンクを載せる
