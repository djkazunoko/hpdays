# hpdays

Hello! Projectメンバーの在籍日数や在籍期間を、ランキングやタイムラインで可視化するWebアプリです。（開発中）

## 実装予定の機能

- 在籍日数ランキング
- 在籍タイムライン
- メンバー詳細

## ローカルでの起動方法

Node.jsとnpmが必要です。リポジトリを取得し、プロジェクトのディレクトリで以下を実行してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されるURLをブラウザで開いてください。

## 使用技術

- React
- TypeScript
- Vite
- Vitest（テスト）
